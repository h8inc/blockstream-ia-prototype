# Blockstream IA Vision — Test Prototype

Click-through prototype for the dashboard-first IA research study (fake data, price pegged at 120,000 USD/BTC so all sums reconcile).

- `index.html` — self-contained, no build step.
- Deep links for moderators: `#dashboard` `#wallet-spending` `#wallet-savings` `#wallet-vault` `#cash` `#price`
- Triple-click the logo to reset to the dashboard.
- Dead ends toast "end of prototype" so participants narrate expectations.
